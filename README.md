# p2UXA

Projeto acadêmico de UX/IHC desenvolvido para praticar construção de interfaces e organização visual.

## Tecnologias

- HTML5
- CSS3

## Como executar

Abra `index.html` no navegador ou utilize o Live Server.

## Objetivo

Aplicar princípios de experiência do usuário e organização de componentes em uma página web.

## Status

Projeto acadêmico.
